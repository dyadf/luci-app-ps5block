# luci-app-ps5block — блокировка обновлений PS5 на OpenWrt

[English version](README.md)

Пакет для OpenWrt с веб-интерфейсом LuCI, который не даёт PlayStation 5 скачать и установить обновление системного ПО. **Игры, патчи, PSN, магазин и все остальные устройства в сети продолжают работать.**

- Включение и выключение одной кнопкой в LuCI (**Службы → Блокировка обновлений PS5**).
- Автоматическое определение консолей по MAC-адресу производителя (Sony Interactive Entertainment) и по имени устройства. Если консолей несколько, это видно в LuCI, и любую можно исключить.
- Два режима: **только консоли** (по MAC) или **вся сеть**.
- Подробное состояние: какие уровни защиты работают, счётчики отброшенных пакетов, проверка DNS прямо на роутере.
- Учитывает **podkop** и **zapret/zapret2**: правила срабатывают раньше них, поэтому трафик обновлений нельзя увести в прокси.
- Встроенная инструкция по настройке консоли.
- Один пакет: `.ipk` для opkg (OpenWrt 22.03–24.10) и `.apk` для apk (OpenWrt 25.x и новее).

## Как это работает

Блокировка устроена в несколько уровней. Каждый закрывает свой способ обхода:

| # | Уровень | Что делает | От чего защищает |
|---|---|---|---|
| 1 | DNS-блокировка | dnsmasq отвечает «домен не существует» для `*.ps5.update.playstation.net` | обычный запрос адреса сервера обновлений |
| 2 | Перенаправление DNS | любой DNS-запрос консоли (порт 53, к любому серверу, IPv4/IPv6) обрабатывает роутер | ручной DNS на консоли (8.8.8.8 и т. п.) |
| 3 | Строгий DNS | внешний DNS отбрасывается **до** podkop | podkop, который маршрутизирует консоль целиком и перехватил бы её DNS |
| 4 | DoT / DoQ | порт 853 закрыт | шифрованный DNS |
| 5 | DoH | закрыт доступ к ~90 адресам публичных DNS/DoH-резолверов (Cloudflare, Google, Quad9, AdGuard, Яндекс, OpenDNS, NextDNS и др.) | DNS через HTTPS |
| 6 | L3 | IP-адреса серверов обновлений отбрасываются; роутер сам узнаёт их и обновляет список по расписанию | консоль, которая уже знает IP сервера |

Все правила (кроме DNS-блокировки в dnsmasq) лежат в отдельной таблице nftables `inet ps5block` с приоритетом **−170**. Это раньше mangle podkop (−150) и раньше очередей zapret, поэтому отброшенный пакет до них просто не доходит. Перезапуск firewall, podkop или zapret таблицу не трогает.

```
пакет от консоли ──► ps5block (−170): DoT / DoH / L3 / строгий DNS ── drop
                           │
                           ▼
                    podkop mangle (−150) ──► NAT (−100): перенаправление DNS на dnsmasq
                           │                                  │
                           ▼                                  ▼
                  forward / zapret / WAN            dnsmasq: NXDOMAIN для домена обновлений
```

Блокируется только `ps5.update.playstation.net` со всеми поддоменами — это системное ПО. Игры и патчи качаются с других доменов и продолжают работать.

## Требования

- OpenWrt **22.03 или новее** с firewall4 (nftables). Это стандарт с 22.03, и это же нужно podkop и zapret2.
- LuCI.
- dnsmasq (стандартный DNS-сервер OpenWrt; `dnsmasq-full` тоже подходит).

## Установка

Скопируйте пакет на роутер (`-O` нужен, если на роутере нет sftp-сервера):

```sh
scp -O luci-app-ps5block_1.0.0-r1_all.ipk root@192.168.1.1:/tmp/   # OpenWrt 22.03–24.10
scp -O luci-app-ps5block-1.0.0-r1.apk     root@192.168.1.1:/tmp/   # OpenWrt 25.x и новее
```

На роутере:

```sh
# OpenWrt 22.03–24.10 (opkg)
opkg install /tmp/luci-app-ps5block_1.0.0-r1_all.ipk

# OpenWrt 25.x и новее (apk) — пакет не подписан ключом OpenWrt
apk add --allow-untrusted /tmp/luci-app-ps5block-1.0.0-r1.apk
```

Перезагрузите страницу LuCI и откройте **Службы → Блокировка обновлений PS5**. Пакет устанавливается **выключенным**. Исключение — если найдены следы старых скриптов, тогда защита сразу включается (см. «Переход со старых скриптов»).

## Первое включение

1. Включите консоль, чтобы она получила адрес от роутера.
2. В LuCI нажмите **«Включить блокировку»**.
3. Консоль появится в списке со статусом **«Заблокировано»**. У PS5 разные MAC-адреса для кабеля и Wi-Fi; оба определяются автоматически, если консоль хоть раз подключалась.
4. Посмотрите блок «Уровни защиты»: все включённые уровни должны быть «Работает», а проверка DNS — «домен обновлений не резолвится».

### Настройка консоли

Эта же инструкция есть внизу страницы в LuCI.

1. **DNS «Автоматически»:** Настройки → Сеть → Настройки → Настроить соединение с Интернетом → ваша сеть → Расширенные настройки → Настройки DNS: Автоматически. Ручной DNS тоже перенаправляется, но «Автоматически» надёжнее всего, особенно с podkop.
2. **Выключите автообновления:** Настройки → Система → Системное программное обеспечение → Обновление системного программного обеспечения и настройки → выключите «Автоматически загружать файлы обновлений» и «Автоматически устанавливать файлы обновлений».
3. **Удалите уже скачанное обновление**, если оно есть. Роутер не может удалить то, что уже лежит на консоли.
4. **Полностью выключите и включите консоль** (не режим покоя), чтобы она забыла закэшированные DNS-ответы.
5. **Проверка:** … → Обновить системное программное обеспечение → Обновить через Интернет. Консоль должна выдать ошибку, а не найти новую версию.

## Режимы

| Настройка | Только консоли (по умолчанию) | Вся сеть |
|---|---|---|
| Кого касается | только консоли PlayStation (по MAC) | все клиенты выбранных сетей |
| DNS-блокировка | вкл | вкл |
| Перенаправление DNS | вкл | вкл |
| Строгий DNS | авто (только для консолей, которых podkop маршрутизирует целиком) | выкл |
| DoT / DoQ | вкл | выкл |
| DoH | вкл | выкл |
| L3 (IP серверов) | вкл | выкл |

В режиме «Вся сеть» опасные для других устройств уровни по умолчанию выключены. Их можно включить вручную на вкладке «Уровни защиты».

**Когда выбирать «Вся сеть»:** если консоль не определяется по MAC (например, на ней включена смена MAC-адреса) или нужна блокировка без исключений.

## Несколько консолей

Если найдено больше одной консоли, LuCI покажет предупреждение и список всех. При включённом автоопределении блокируются все. Чтобы оставить какой-то консоли обновления, нажмите **«Исключить»** напротив неё. Консоль, которая не определилась сама, можно добавить вручную в разделе «Консоли, добавленные вручную».

## Совместимость с podkop, zapret и DoH

- **podkop.** Совместим. Отбросы DoT/DoH/L3 срабатывают раньше podkop: на тестовом стенде с правилами podkop трафик консоли к серверу обновлений до него **не дошёл ни разу**. Тонкость в DNS: перенаправление в ядре всегда выполняется на этапе NAT (−100), а podkop перехватывает трафик раньше (−150). Поэтому для консолей, которых podkop маршрутизирует **целиком** (`fully_routed_ips`, включая подсети), автоматически включается **строгий DNS**. Внешний DNS отбрасывается на −170, и консоль вынуждена спрашивать роутер, а запросы к роутеру podkop не трогает. Если в podkop поменять список, правила перестроятся сами при следующем обновлении (по умолчанию раз в 20 минут) или сразу по кнопке «Применить правила заново». **Не добавляйте домены playstation в списки podkop** — пакет предупредит, если найдёт их.
- **zapret / zapret2.** Совместим. zapret работает с исходящим трафиком в WAN, а отброшенные пакеты туда не попадают.
- **DoH на роутере (https-dns-proxy и т. п.).** Совместим: это вышестоящий сервер для dnsmasq, а запись dnsmasq отвечает раньше.
- **AdGuard Home.** Если он заменяет dnsmasq на порту 53, DNS-уровень не работает: добавьте `||ps5.update.playstation.net^` в его чёрный список. Остальные уровни работают.

## Командная строка

```sh
ps5block status          # подробное состояние
ps5block enable|disable  # включить / выключить
ps5block mode mac|global # режим
ps5block detect          # найденные консоли
ps5block add AA:BB:CC:DD:EE:FF "PS5 гостиная"   # добавить вручную
ps5block exclude AA:BB:CC:DD:EE:FF              # исключить консоль
ps5block remove AA:BB:CC:DD:EE:FF               # забыть добавленную вручную
ps5block refresh         # обновить список IP серверов и консолей
ps5block ruleset         # показать правила nftables, которые будут загружены
```

Настройки хранятся в `/etc/config/ps5block`, журнал — `logread -e ps5block`.

## Переход со старых скриптов

При установке пакет сам убирает следы прежних скриптов:

- **`ps5_update_block.sh`** (pureair): 41 запись в dnsmasq, включая `gs2.ww.prod.dl…` и `sgst.prod.dl…`, которые, вероятно, мешали загрузке игр.
- **`ps5block.sh`** (одиночный скрипт): правила `ps5blk_*` в firewall, include, cron, `/etc/ps5block.conf`.

Пользовательские записи dnsmasq, правила firewall и задачи cron не трогаются. Если старая блокировка была активна, пакет сразу включается и переносит MAC-адреса консолей, так что защита не прерывается.

## Удаление

```sh
opkg remove luci-app-ps5block   # или: apk del luci-app-ps5block
```

При удалении убираются таблица nftables, запись в dnsmasq и задача cron. Файл `/etc/config/ps5block` остаётся; удалите его вручную, если он больше не нужен.

## Решение проблем

| Симптом | Что проверить |
|---|---|
| Консоли нет в списке | Консоль должна получить адрес от этого роутера. Проверьте `ps5block detect`. Если её нет — добавьте MAC вручную (PS5: Настройки → Система → Системное программное обеспечение → Информация о консоли). |
| Уровень «Не загружен» | Нажмите «Применить правила заново» и прочитайте ошибку nftables на странице или в `logread -e ps5block`. |
| «домен обновлений всё ещё резолвится» | DNS обслуживает не dnsmasq (например, AdGuard Home), или запись удалили вручную. Нажмите «Применить правила заново». |
| Консоль всё равно нашла обновление | Обновление было скачано раньше (удалите его на консоли); консоль подключена к другой сети; консоль не в списке блокируемых. |
| Проблемы с чем-то, кроме обновлений | Выключите L3 на вкладке «Уровни защиты»: адреса CDN общие с другими сервисами. |

## Ограничения

Роутер контролирует только свою сеть. Консоль, подключённая к другой сети (раздача с телефона, другой роутер), или обновлённая с USB-накопителя, блокировкой не покрывается. Sony может сменить домены обновлений; список доменов можно поправить в LuCI (вкладка «Дополнительно»).

## Сборка из исходников

```sh
# быстрая сборка .ipk и .apk без SDK
PO2LMO=/path/to/po2lmo APK=/path/to/apk ./build.sh       # → dist/

# или в OpenWrt SDK: положите каталог в feeds/luci/applications/
make package/luci-app-ps5block/compile
```

`po2lmo` собирается из `luci/modules/luci-base/src`, `apk` — из apk-tools 3.x.

## Как пакет проверялся

Пакет проверялся в эмулированном окружении OpenWrt: busybox ash, настоящие `uci`, `jshn`, `jsonfilter`, `opkg` и `apk` 3.0, собранные из исходников OpenWrt, и настоящий `nft` с ядром Linux. Проверены:

- установка, переустановка и удаление через opkg и apk, миграция со старых скриптов;
- живой трафик через мост с «консолью» и «телефоном», с правилами podkop и без них;
- отрисовка страницы LuCI на английском и русском.

**На физическом роутере пакет пока не запускался.** Если что-то пойдёт не так, пришлите вывод `ps5block status` и `logread -e ps5block`.
